{% comment %} _card.html — single carousel card Accepts: item - the model instance (movie / anime / manga) rank - integer position (forloop.counter) detail_url - the resolved detail URL, passed in by the parent template content_type - "movie" / "anime" / "manga" — enables the year + bookmark row saved_ids - set of the current user's bookmarked item IDs, used to render the star filled or empty Layout: the card is a fixed-height flex column. The cover has a fixed height; the (cover + title) flexes to fill the remaining space, so the year + bookmark row is pinned to the bottom on every card, regardless of how long the title is. Covers use object-cover, so source images of varying dimensions fill the box without stretching (minor edge cropping only). When content_type is passed, the bottom row renders with the year (left) and, for logged-in users, a compact bookmark star (right). All three content types pass content_type, so every card shows this row. The card reads `item.year` for the year — a real field on Anime/Manga, a property on Movie — so the template stays uniform. {% endcomment %}
